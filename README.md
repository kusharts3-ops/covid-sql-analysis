# COVID-19 Data Analysis in SQL

## Project Overview
Analyzed 429,435 rows of global COVID-19 
data using SQL Server Management Studio.

## Tables Created
- CovidDeaths
- CovidVaccinations

## Analysis Performed
- Death Rate by Country
- Infection Rate vs Population
- Highest Death Count by Country
- Global Numbers Per Day
- Rolling Vaccinations
- % Population Vaccinated

## Tools Used
- SQL Server Management Studio (SSMS)
- Dataset: Our World in Data

## Key Findings
- Analyzed 429,435 rows of data
- Used Window Functions and CTEs
- Performed JOIN operations on 2 tables
